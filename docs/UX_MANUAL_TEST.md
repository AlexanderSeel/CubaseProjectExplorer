# Windows UI manual acceptance checklist

Use the newest successful [Windows CI run](https://github.com/AlexanderSeel/CubaseProjectExplorer/actions/workflows/windows-ci.yml) and extract the Uno Desktop Windows artifact. This is a **human test checklist**, not a claim of visual approval. The Uno migration is incomplete; perform checks for screens that exist and record missing functionality in `PLAN.md`.

1. Launch and check **Project Library**. Open representative CPR/BAK and DAWproject files; verify metadata and candidate/evidence labels.
2. Scan a folder containing CPR, recognized RIFF/NUND BAK, DAWproject and unrelated BAK files. Check progress, errors, partial results, cancellation and rescan behavior.
3. Check the shared page title/action header. In Project Library, verify search and file type stay in the primary command row, advanced filters open in a dismissible flyout, and **Scan issues** opens a dismissible popup with issue code, message and path. In Overview, verify **Field availability…** opens its detail popup and Escape/outside click dismisses both popups. Verify the result summary updates and selecting a result opens the project overview.
4. Visit Tracks, Plug-ins, Routing, Audio/MIDI I/O, Statistics, Compare, Local inventory, Reports/tools and Settings. Open a CPR/BAK from the library and verify it is re-read from disk; Tracks shows supported records as candidates, and Audio/MIDI I/O shows any recovered native audio-path, mixer or typed-field observations with source offsets and unverified labels. Reopen after changing the source to confirm the saved snapshot refreshes. Empty candidate sections must say that no supported observation was found, not that the data is absent. On Statistics, verify the library-wide ranking updates from saved snapshots, exact display labels with different export-local IDs do not create false duplicate products, selecting confirmed rows reveals their saved project sources, candidate CPR/BAK tokens stay in their collapsed unverified section and reveal only exact-token source projects, and unknown references are excluded. Confirm unavailable CPR fields remain unknown/candidate and actions operate on copies or exports only.
5. In Compare, load two DAWproject exports and review the suggested A → B track matches. Check long/duplicate names, deliberately leave a track unmatched, choose a renamed counterpart, and try selecting the same B track twice (save must fail clearly). Save valid matches, reload the pair, restart, and swap A/B: saved choices should return without another prompt. Change parsed comparison data and reload: review must appear again. Use **Review track matches…** to revise choices and **Compare once without saving** to leave the database unchanged. Verify track destinations, parent relationships, plug-in owners, and route comparisons use the selected matches; raw XML IDs alone must not establish cross-file identity. Check the review list/dropdowns with keyboard and screen reader, plus a zero-track pair and a database-write failure.
6. On Library database, use **Select existing database…** to choose a compatible library or backup. Verify the Next launch path updates while Current session and counts stay on the active database. Cancel and try an invalid/incompatible file: the previous selection must remain. Restart and verify the chosen library's projects, catalog and saved track matches load. Check the picker filters, long paths, keyboard access, error text and disabled buttons during validation; check **Copy database to new location…** still provides a separate copy workflow.
7. In Project Library, choose each **Group projects by** mode and check visible headers, counts, sorting, search/type/evidence filters, empty groups, project selection, exports and return navigation. Copy a project byte-for-byte into a second scanned root and verify it appears once; remove the previously chosen copy, rescan the new root and verify the remaining path is listed once. Check that checksum failures remain visible as issues and do not claim deduplication. Modified year/month means file modification date, not creation or recording date. Check a large collection and more than 250 folders: grouping must not drop rows.
8. Open Project Calendar with normal indexed projects, then with a project whose source file has moved or is offline. Confirm the year picker and 12-month calendar remain visible even when every date is unknown. Dated projects should use current file attributes when available; projects without a readable current timestamp may use the last stored file-modified timestamp and otherwise remain selectable under **Date unknown**. If the library is empty, verify the empty state offers a clear route back to Project Library. Selecting either dated or unknown-date entries should open that project overview.
9. Open whistleaway's DAWproject export and visit Routing. Check the visual **Feeds in → selected channel/devices → Goes to** diagram against Cubase. Use channel search/type filters, the picker, and the coloured feeder/destination buttons to change focus; verify the selected device list and output-path navigation update. Check solid output/dashed send connections, fan-in/out paging, fit/zoom, responsive channel-sidebar visibility, and the complete text connection disclosure. Test keyboard focus, unresolved/duplicate identities, empty connections and cycles. No edge to physical hardware or a final output may be invented; native CPR must explain unavailable connections. Compare the layout with the user's signal-flow reference rather than a TreeView.
10. Visit Plug-ins while the automatic local inventory scan is running. Confirm cached images appear and cards refresh after the scan without navigating away; selected card/search must remain usable. Check images for Vst3Plugin exports, CID-named Cubase bundle resources, missing/ambiguous resources, scan failure and cancellation. Resource artwork must not change installation/loadability status. Select EQ and inspect the exported band parameters/units; expand Overview's warp disclosure for whistleaway and compare the declared coordinates with its XML. Check fallback icons and image/text alignment at narrow/wide widths.
11. On Audio / MIDI I/O, run **Check declared external media** for a DAWproject with both embedded and external references. Confirm relative and absolute paths explicitly marked external report present/missing/inaccessible/unsupported, duplicate paths are counted once as unique checks, embedded audio stays unchecked, and no media bytes change. Try a native CPR/BAK project, unknown external flags, URIs, and a path through a link/reparse point: these must remain unknown/unsupported without claiming media is missing. Export the handoff checklist and confirm it includes safe relative paths and status but omits absolute/URI paths. The presence check does not establish valid audio or DAW loadability.
12. Open Sample Finder and MIDI tracks for indexed DAWproject exports. Filter samples by format and search project/track/path/folder; confirm identical filenames remain distinguishable by track, project and folder. Verify embedded folders are identified as archive entries and external folders resolve beside the export or use the declared absolute folder. Select a sample and explicitly prepare playback; verify it does not autoplay, built-in transport controls work for supported formats, and stopping/changing selection releases temporary files. On a PCM/float WAV, compare the peak overview/channel/rate/frame metadata to the selected file; on MP3/FLAC or malformed WAV, verify the app reports waveform unavailable without blocking playback. Export a sample copy and confirm it matches the selected media while the source project/reference remains unchanged. Choose **Find byte-identical files…** with a narrow format/search filter and verify only those filtered external audio references are scanned after explicit activation. Exact copies at different paths should group; repeated references to one resolved path should count once; altered or differently encoded audio should not group unless bytes match. Check progress, cancellation and the 500-file / 150 MiB per file / 1 GiB total limits, and verify source bytes remain unchanged. The scan is not semantic or audible similarity analysis. Choose **Collect project media…** and inspect `manifest.json`: included external files appear once, embedded/missing/unknown/unsupported references are labelled, absolute source paths are redacted, and output names do not preserve unsafe source paths. Verify attempts to target the project or a referenced file are rejected. In MIDI tracks, confirm rows identify project and track kind; inspect the piano roll for note pitch, duration and declared time units; verify clip-nested or mixed-timebase notes are not flattened, and large tracks report when the display is decimated. Unsupported/ambiguous rows explain why export is disabled. Export one eligible track and inspect the resulting `.mid` in a MIDI editor. Test empty indexes, stale index rows, large/unsupported formats, inaccessible files, keyboard selection and narrow-width layouts. CPR/BAK media and MIDI extraction remain unknown.
13. On Project Library, project Tracks/Plug-ins, Sample Finder, MIDI tracks, Statistics rankings and Search everything, switch between **Details** and **Cards**. Confirm view switching does not invoke a row action or navigate away. Cards should load in responsive pages of at most 32 rows; use Previous/Next through a large result set and verify the row count, selection, grouping and filters remain coherent. Click each sortable DataGrid header twice and check both value order and direction icon. Choose each group mode; collapse/reopen headings with mouse and keyboard, and confirm filters preserve group state and selection where the item remains visible. Right-click rows/cards and verify the offered action matches that dataset. In Search everything, search one project name, audio filename/path, MIDI track and plug-in label; test multiword matches spanning title/context, every scope, no results and the 2,000-result narrowing state. Activate results and verify they return to the correct project or media/MIDI filter. Check long Unicode paths, empty/error states, 100–200% DPI, light/dark/high contrast, screen-reader names, and large indexed collections. Live review is required; a passing build alone is insufficient.
14. On cold startup, confirm the in-app loading surface appears immediately with an active spinner, reports loading saved project snapshots/scan folders and plug-in/catalog counts, then shows accurate totals and dismisses. Navigate through at least four pages; verify the location strip shows only the immediately previous page and current page while Back/Forward still traverse the full history. Rescan with multiple indexed roots and verify changed snapshots update while other roots remain listed; make the last scan folder unavailable and check the app requests a replacement folder. In Plug-in Catalog, import two sources and confirm both source-attributed sets remain searchable, repeat one source and check it updates rather than duplicates, then enable image downloading and confirm only bounded source-declared HTTPS images enter the DB. Disable the option and confirm no image network fetch occurs. Check progress text, error handling, image rights attribution, app icon at taskbar size, keyboard access, and startup duration.

Test 1280×720, 1920×1080 and 2560×1440 when available at 100%, 125%, 150% and 200% DPI; include light/dark/high-contrast, long filenames, Unicode, empty/no-results/error states. Use keyboard-only Tab/Shift+Tab and a screen reader where possible. Check overlaps, clipping, focus order and large-library scroll behavior.

Record screenshots, artifact/run ID, OS/DPI details, reproducible problems and manual acceptance results in PLAN.md. **A green CI build does not constitute visual acceptance.**

For the native MIDI browser: choose Native CPR notes; verify the exported-track
pane reserves no space. Select project/part groups, including duplicate names
at different offsets and mixed encodings within one part. Compare the compact
note table with the raw JSON precision and source offsets. Confirm the plot's
axis says stored units are unverified and no native MIDI export is offered.
Filter by project, possible track/part or pitch; test zero results and clear
the query. Select Exported MIDI with no confirmed tracks and check its explicit
empty state. At narrow width, a compact project/part selector should replace
the group grid above the selected-group plot/table without horizontal clipping. Review the
Evidence & source popup with keyboard and a screen reader. Re-scan projects
before expecting new parser layouts in saved indexes; index refresh alone
does not re-read project files.
